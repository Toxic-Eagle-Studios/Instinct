BUILD A REAL, RUNNABLE APPLICATION CALLED INSTINCT. This is the actual app concept, not a landing page or mockup.

PLATFORM: Choose WEB APP (React frontend + Node backend), mobile-first for Samsung Galaxy S25 Ultra and MacBook. PRODUCT: INSTINCT = ONE PERSONAL SECOND BRAIN combining three connected abilities:
1. WHILE YOU'RE AT IT: Contextual reminders. "Remind me to ask Dad about Friday" stores a reminder tagged to Dad. When the user later types or says "I'm heading to Dad's", show the saved Dad reminder, without GPS tracking.
2. EXACTLY / REMIND ME: One searchable memory for facts, normal orders, preferences, steps, past solutions and reminders. "What's my normal pizza order?" must return a previously saved pizza preference (or admit nothing was saved). Allow viewing, correction, deletion, completion, export/import.
3. UNDO IRL: "I accidentally deleted something" launches a clear, careful recovery guide. Allow saving the successful solution into shared memory for later retrieval.

SCREEN / UI: INSTINCT logo/name, one universal capture field, optional voice transcription and photo capture, contextual results section, four compact tabs (Home, Memory, Undo IRL, Settings), edit/delete, search filters (reminder/preference/solution/note), local data privacy controls. Design: black/graphite with restrained acid-green accents, crisp premium typography, very simple to understand within five seconds. Phone-first, usable with touch and keyboard, no giant marketing page.
